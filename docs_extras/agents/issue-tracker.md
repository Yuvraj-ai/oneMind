# Issue Tracker

Issues live in **GitHub Issues** on this repo: https://github.com/Yuvraj-ai/oneMind

Authentication: PAT stored in `.env` as `GITHUB_PAT`.

## Tools

- CLI: `gh` (GitHub CLI)
- Create: `gh issue create --title "..." --body "..." --label "..."`
- List: `gh issue list --label "..."`
- View: `gh issue view <number>`
- Close: `gh issue close <number>`
- Edit: `gh issue edit <number> --add-label "..." --remove-label "..."`

## Conventions

- One issue per ticket. Blocking edges are expressed as task lists or references in the body.
- Agent-created issues always start with: `> *This was generated by AI.*`
- Triage labels are applied per `docs/agents/triage-labels.md`.

## PRs as a request surface

Off. External PRs are not triaged as issues.

## Wayfinding operations

- **Map**: a single issue labelled `wayfinder:map`
- **Tickets**: child issues of the map, referenced by number
- **Blocking**: expressed in the issue body under "Blocked by" (GitHub has no native blocking relationship)
- **Frontier query**: `gh issue list --label "wayfinder:ticket" --state open` then filter for unblocked
